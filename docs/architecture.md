# 小李项目总体架构设计（v2）

> 2026-08-20 建立，2026-08-22 更新到 v2。核心理念：**小李 ≠ DeepSeek网页版聊天**——差别全在"壳层"。
> DeepSeek 只是发动机（大脑层），我们的价值在于围绕它搭建完整的"壳"。

## 一、项目定位

| | 网页版聊天 | 小李 |
|---|---|---|
| 你问 | 它答 | 她接住你 |
| 记忆 | 无 | 记得你的一切（还会半衰期式遗忘） |
| 情绪 | 无 | 有心情、有脾气、会吃醋会哄 |
| 主动性 | 无 | 会主动找你（配额克制） |
| 声音 | 无 | 台湾腔甜妹（情绪会变声） |
| 形象 | 无 | 会动的 Live2D + 表情 |
| 交互 | 打字 | 打字/按键说话/**免按键通话** |

## 三、上下文管理方案（防超长、防失忆）

**核心思想：模型上下文 = 工作台；本地文件 = 日记本**

1. **日记本**：全部聊天记录存本地文件（data/chat_history.json），永不丢
2. **工作台**（每次只送这些给模型）：
   - 人设提示词（常驻）
   - 最近 60 轮对话
   - 档案记忆相关条目（按需检索，v2 语义升级）
   - 当前心情状态（情绪层）+ 程序注入块（连珠炮/提醒/纪念日/承诺槽/打断续说）
3. **超长压缩**：60 轮前的旧对话 → 增量摘要（v2 M3：【记忆】+【情绪线】两段式）留在工作台
4. **防失忆**：记忆在硬盘，不在对话窗口——换窗口、重启程序都记得

## 五、设计原则

1. **仿真真人**：一切机制以"像真人"为验收标准，依据实证研究（docs/research/）
2. **壳层为王**：核心价值在壳层机制，不在模型本身
3. **记忆在硬盘**：任何对话窗口都不是记忆的载体
4. **程序是游戏主持人**：机制触发归程序，LLM 只负责"怎么演"（连珠炮/提醒/小脾气都靠程序注入，不赌 LLM 自觉）
5. **优雅降级**：任何增强（向量/情绪TTS/Live2D）失败都不影响主链路
6. **不做操纵**：不用愧疚式话术挽留用户
7. **小步快跑**：每层独立可测，地基不稳不盖楼
