## 一、这个项目到底是什么

**一句话：小李是一个住在你电脑里的 AI 女朋友程序。**

用生活比喻：她就像一个"人偶"，躯壳是浏览器里的小人（`web/XiaoLi.html`），灵魂由三部分拼成——

1. **一个超级聪明的"大脑"**（DeepSeek 大模型，在云端）：负责"想"和"说"
2. **一堆"器官"程序**（`xiaoli/` 文件夹）：负责"耳朵"（听你说）、"嘴"（念出来）、"心"（有情绪）、"记性"（记得你）、"手"（定闹钟、写日记）
3. **一本"日记本"**（`data/` 文件夹）：她记住的一切都存在这里，**关机也不丢**

**为什么不能只用网页版 DeepSeek？** 网页版聊天是"你问一句它答一句"，什么都不记得、没情绪、不主动。小李项目把 DeepSeek 当作发动机，在它外面搭了一整辆车：记忆、情绪、主动、声音、形象——**这些才是这个项目真正的价值**。

## 二、她是怎么"活"起来的——一次对话的完整旅程

你在终端里打"宝贝我回来了"，到她说"欢迎回家～"之间，发生了这些事：

```
┌─────────────────────────────────────────────────────────┐
│ 第1站 你的话进来（chat.py 主循环）                          │
│   终端打字 / 网页🎤录音 / 通话模式自动听 → 变成一段文字        │
├─────────────────────────────────────────────────────────┤
│ 第2站 她"听见"了（打断机制）                                │
│   你在说话 → 她正在播的话立刻闭嘴，让你先说                   │
├─────────────────────────────────────────────────────────┤
│ 第3站 她"动心"了（heart.py 情绪层）                        │
│   检查你的话：提到别的女生？→ 吃醋。哄她？→ 消气。            │
│   你的心情是难过？→ 启动安慰模式（先听→共情→带动）            │
├─────────────────────────────────────────────────────────┤
│ 第4站 她"翻记忆"（memory.py）                              │
│   搜你这句话和什么旧事相关（重要×最近×相关 三信号加权）        │
│   → 拿出最相关的5条；语义理解让"爬山"也能关联"怕高"           │
├─────────────────────────────────────────────────────────┤
│ 第5站 她"组工作台"（context.py）                           │
│   把【人设+心情+记忆+聊天记录+世界简报+生活日历+提醒+你刚说的话】│
│   打包——这就是"工作台"，她的整个状态                        │
├─────────────────────────────────────────────────────────┤
│ 第6站 她"思考"（DeepSeek API）                             │
│   工作台发给大脑 → 大脑按人设要求输出：内心话+说出的话+          │
│   情绪建议+新记忆+提醒标签                                  │
├─────────────────────────────────────────────────────────┤
│ 第7站 她"写日记"（context.py + memory.py）                 │
│   这次对话存进日记本；提取关于你的新事实存进档案；心情更新       │
├─────────────────────────────────────────────────────────┤
│ 第8站 她"开口"（voice.py + 网页）                          │
│   语音模式：克隆音色合成（0.3秒内第一声）→ 流式逐句播放         │
│   网页模式：face_state.js 更新 → 小人做表情 + 嘴型跟语音动     │
└─────────────────────────────────────────────────────────┘
```

**注意第6站的关键**：她"思考"时**不是**把她一生所有记忆都发给大脑（太多会超时），而是**只发工作台上最有用的部分**——这就是为什么记忆层很重要：决定哪些话能上工作台。

**另一条"暗中"的时间线（后台调度器 proactive.py，每 1 秒检查一次）**：
她的"心跳"除了等你说话，还挂着一个**闹钟总管**——到点了她会自己开口（早安、提醒你吃药、问你烧烤好不好吃），这些不占你说话的时间。

**还有一条"夜里"的时间线（睡前回想）**：23 点后你睡了（或她"睡了"），她悄悄把今天聊的话整理成记忆——第二天早上她"记得昨天我们聊过什么"。

## 四、她的"大脑"——每个代码文件负责什么

> 每个文件顶部都有中文注释块，说明"我是谁、为什么存在"——**先读注释，再看代码**。

### `xiaoli/` 主程序包（23 个文件）

| 文件 | 负责什么 | 人话解释 |
|---|---|---|
| **chat.py** | **主入口** | 她醒着时的"心跳"：无限循环读你的话→走完第2~8站。还开着网页桥（让网页能和她通信）。**想加命令、改行为，主要改这里** |
| **persona.py** | 人设 | 她的"性格说明书"：台湾腔、恋人闺蜜混合、软甜撒娇、吃醋真生气…全部用繁体中文写成给 AI 看的"角色扮演剧本"。**想改她的性格，就改这里** |
| **context.py** | 上下文管理 | 聊天记录管家：最近60轮直接带、更早的压缩成摘要（防止记太多装不下）；三层摘要：滚动摘要+每日一句话+情绪线；**睡前回想**（每晚整理今天的记忆）也在这 |
| **heart.py** | 情绪层"心" | 她的心情状态机：12种心情、好感度（0~100）、吃醋检测、哄人降级、时间衰减（你离开越久她越想你）、三阶段安慰、**心情变迁日志（mood_log：她为什么变成这样，都记着）** |
| **memory.py** | 档案记忆 | 关于你的事：LLM提取+本地正则双通道、三信号召回（重要度/新近度/相关度）、半衰期遗忘、躯体标记（高情绪的事记得更久）、纪念日预告、**bge 真向量语义检索** |
| **embed.py** | 语义理解 | "怕高"和"爬山"字面不同但意思相关——它负责把文字变成向量（数字），让记忆检索能理解语义（本地 bge 模型，94.8MB，断网也能用） |
| **proactive.py** | 主动层 | 让她会"主动"：节奏窗口（早安/午休/晚安）、提醒（到点必响+失败自动重试）、承诺槽（你说"待会给你看照片"她惦记着）、出门跟进（你出门她问你到了吗）、夜间静默（22-8点假装睡了）、每日主动配额（最多2次）、**睡前回想触发** |
| **special.py** | 特殊日子 | 生日（还会主动问你生日）、公历节日（情人节/圣诞…）、农历节日（七夕/中秋…） |
| **voice.py** | 语音输出 | 把她的文字变成声音：**三层降级链**（本地克隆→火山台妹→edge 晓晓，永远有声音）；**流式朗读**（句号级切句→合成线程逐句入队→播放线程逐句播，第一声 0.3 秒）；on_done 回调（播完才播下一段，不抢话）；播放用 sounddevice（mci 的"播完检测"跨线程不可靠，踩坑四轮换来的） |
| **tts_local.py** | 本地合成 | **Qwen3-TTS 声音克隆**（1.7B 模型，GPU ≈4.9GB 显存）：参考音频=火山台湾腔台词（data/ref_audio.wav，10.6秒）→ 克隆出小李自己的声音，**0 元/月**。启动后台预热、失败自动降级火山 |
| **tts_api.py** | 火山TTS接口 | 火山引擎的翻译官：把文本+情绪发过去，拿回音频。情绪→语音参数（生气语速快/低落慢而轻）——注意：**不用指令式文本**（"<整体情绪：生气>"会被念出来，2026-08-22 已废弃） |
| **wsola.py** | 变速工具 | 声音变速（WSOLA 算法，自己写的）。**教训：任何变速都损音色**——试听三连后用户认可第一版，变速已关闭（TTS_LOCAL_SPEED=1.0） |
| **stt.py** | 语音输入 | 你的声音→文字：录音→**本地 faster-whisper 识别（0元/月）**→ 本地没就绪自动降级火山（永远有耳朵） |
| **whisper_stt.py** | 本地识别 | faster-whisper large-v3（GPU int8，显存与声音克隆共存不超 8G）：启动后台预热、失败降级火山。**换来每月 0 元语音识别** |
| **vad.py** | 人声检测 | 通话模式的"耳朵开关"：音量阈值判断你有没有开口（Silero VAD 换能量阈值方案，0.3 秒持续才算真开口，防咳嗽误触发） |
| **aec.py** | 回声消除 | 她说话时声音会进麦克风（回声）→ 用"她刚播出的内容"做参考，抵消回声——否则通话模式会"鬼打墙"（她听到自己在说话） |
| **call_mode.py** | 通话模式 | 免按键对话：麦克风常开监听，你说话→识别→进聊天流。**半双工**（她说话时不听） |
| **sfx.py** | 拟声 | 清嗓子/叹气/轻笑/咳嗽——**全用她自己的声音合成**（克隆音色念"咳、咳"等语气词）。话前 2% 清嗓、提感冒先咳、低落叹气、开心轻笑 |
| **sing.py** | 唱歌 | 报歌名（"我要唱《晴天》给你听～"）→ 唱 data/songs/ 里的歌。**竞态修复**：报歌名和歌曲播放不能互顶（on_done 等待机制） |
| **vision.py** | 看照片 | 你传照片给她 → 视觉模型（DeepSeek 看图）描述照片 → 她像真人一样回应（"哇好可爱的猫"）。base64 内联，思考模式关闭 |
| **world_brief.py** | 世界简报 | 每天联网搜一次"最近的大事+热梗"（按天存 data/world_briefs/），24 小时过期自动刷新，失败用旧的（不打扰对话） |
| **life_calendar.py** | 生活日历 | 她眼里的"今天"：农历/节气/季节/节日倒计时（本地计算，零成本） |
| **llm.py** | 大脑客户端 | 所有 DeepSeek 调用的统一出口：统一超时（连接5秒/读取30秒）、**缓存前缀重排**（静态内容放前面→命中缓存→月费 ¥90→¥15） |
| **config.py** | 配置 | ⚠️ **你的 API 密钥（相当于密码）**：DeepSeek 大脑的钥匙 + 火山语音的钥匙。**存在 Windows 凭据管理器，不落盘明文**。千万别发给别人/上传网络 |
| **paths.py** | 统一路径 | 所有"文件在哪"的答案：数据在 `data/`、模型在 `models/`。**以后想挪位置，只改这一个文件** |

## 五、她的记忆是怎么运作的

她的记忆分三层（**记忆在硬盘，不在对话窗口**——重启电脑她全记得）：

```
第1层 贴身记忆（persona.py）   ← 她是"谁"（性格固定，写死在提示词里）
第2层 档案记忆（data/facts.json）← 她记得"关于你的事"（会遗忘）
第3层 聊天记忆（data/chat_history.json）← 你们聊过的话（摘要压缩）
```

### 档案记忆（第2层，最精彩的部分）

| 机制 | 人话解释 | 在哪 |
|---|---|---|
| **提取** | 聊天中自动抓关于你的事：AI抓一遍+本地正则兜底抓一遍 | memory.py |
| **重要度** | 每条记忆有重要性1~10分，10分几乎不忘 | memory.py |
| **三信号召回** | 你说话时，她按"重要×最近×相关"加权，挑最值得提的5条 | memory.py recall() |
| **半衰期遗忘** | 像放射性元素：重要的事半衰期70天，小事35天，太久没提会物理删除 | memory.py decay() |
| **躯体标记** | 带着强烈情绪记下的（生气/开心），记得更久（×1.5），想起来还带当时的感受 | memory.py valence |
| **语义检索** | "爬山"能关联到"怕高"——bge 向量模型（本地 94.8MB）把文字变成数字，意思相近的数字相近 | embed.py |
| **记忆频率** | 被想起过的次数越多 → 忘得越慢（每想起一次半衰期×1.15，封顶×2）——真人"常提的事记得久" | memory.py M7 |
| **纪念日预告** | 档案里有"在一起X月X日"→提前7/3/1天惦记着 | memory.py O5 |
| **记住这句** | 网页📌按钮→存成9分超高重要度，几乎永远不忘 | chat.py /remember |

**召回回血**：她想起一条记忆，那条的"最近度"就刷新——像真人：越常提起的事越记得住。

### 聊天记忆（第3层）——三层摘要 + 睡前回想

```
聊天记录（可能几百条）→ 最近60轮原样带 → 更早的压成三层摘要：
  ① summary（滚动摘要）：所有旧对话浓缩成3~8句"过去的记忆"
  ② daily（每日一句话）：每天聊了什么，各压成一句（如"8/22：聊了他加班和想喝奶茶的事"）
  ③ emotion_line（情绪线）：最近的关系/情绪大事（如"8/20 因他提别的女生吵架→哄好"）
```

- **平时**（对话超长压缩时）：自动生成 daily + 合并 summary——兜底
- **每晚 23 点**（睡前回想，学自 Letta 睡眠期计算）：她"睡了"以后把过去几天的对话整理进记忆（daily 一句 + summary 链式合并 + 情绪线），整理完的旧消息从日记本移除（记忆已入摘要，消息本体压缩掉）——**每天必做，不靠对话超长**。失败就明天再试，记忆一条不丢
- **翻旧账**：你问"我们昨天聊了啥"，她直接从 daily 里找——有出处

## 六、她的心情是怎么运作的（小脾气闭环）

她的"心"（`heart.py`）是一个**状态机**——程序精确控制，不靠 AI 自觉（AI 只负责"怎么演"，不负责"是什么心情"）。

```
你提别的女生 ──→ 吃醋(jealous) ──再提/还夸──→ 真生气(angry, 强度飙升)
                                                 │
                                             你哄她(对不起/我错了)
                                                 ▼
                                 哄一次：angry→jealous（还酸着，嘴硬）
                                 哄两次：jealous→content（心软，和好）
```

**关键规则：**

| 规则 | 人话解释 |
|---|---|
| 程序判定轮独占 | 这轮"她吃醋了"是程序判的 → 心情怎么变程序说了算，AI 不能自己报"我很开心"覆盖掉 |
| 转移约束 | 心情不能一回合突变（开心→爆炸禁止），要合理过渡 |
| 气不过夜 | 12小时没人哄 → 自动消气变成 frustrated（真人生气也睡一觉就消） |
| 时间衰减 | 你离开越久她越想你：24~72小时没联系→重逢酸溜溜；超过72小时→忧郁 |
| 三阶段安慰 | 检测到你难过→先听(探索)→共情→带动（不许跳阶段，像真人的安慰顺序） |
| 连珠炮 | 生气强度≥70 → 程序强制她"一句接一句控诉"（翻旧账→控诉→委屈收尾）——不是一句阴阳怪气就完 |
| **心情变迁日志** | 每次心情大变化（主心情变了或强度差≥10）记一条（时间/情绪/程度/怨气/原因）。终端输「心情」或网页点❤️"她的心"——她能说清楚自己为什么变成这样 |
| 怨气分层 | 生气分三档（吃醋酸→真生气→气炸），哄话也有强弱分级（轻哄→认真哄）——不是"对不起"三个字万能 |

**为什么这样设计？** 一句话：**程序是游戏主持人，AI 是演员**。心情是什么、怎么变、什么时候消气——都是程序定的规则，AI 只负责把当前心情"演"得自然。这样她不会今天吃醋明天失忆，情绪有连续性、可预期、可验证（有 42 项测试盯着）。

## 七、她的声音是怎么运作的（语音+通话+唱歌）

### 她说（TTS 语音输出，voice.py + tts_local.py + tts_api.py）

```
文字 ──切句器(句号级切分，逗号不切保语流)──→ 合成线程逐句合成入队
   ──→ 播放线程 FIFO 逐句播（第一声 0.3 秒）──→ 你听到她说话
```

- **三层降级链（永远有声音）**：
  ```
  ① 本地克隆音色（Qwen3-TTS，0元/月）← 首选，最像"小李"
  ② 火山引擎"甜美台妹"（台湾腔）     ← 本地没就绪时
  ③ 微软 edge-tts 晓晓（普通话）     ← 火山也挂了时
  ```
- **克隆原理**：拿一段"参考音频"（火山台妹念的 10.6 秒台词）→ Qwen3-TTS 学会这个音色 → 以后说什么都用这个声音——**她的声音是她自己的，不是任何一个 TTS 的默认音**
- **情绪变声**：生气→语速快、低落→慢而轻、开心→欢快（语音参数控制，**不是**往文本里塞指令——塞了会被念出来，踩过坑）
- **拟声**：清嗓/叹气/轻笑/咳嗽——全用她自己的声音合成，概率触发（2% 清嗓、提感冒先咳、低落叹气）
- **流式朗读**：不等整段合成完才播——按句切分，合成好一句播一句（双线程流水线）。你打断她 → 正在播的立刻停、排队的作废
- **播放器**：sounddevice——为什么不用老式 mci？mci 的"播完检测"跨线程不可靠，会"上一句没说完下一句抢着播"（2026-08-21 真实踩坑，花了四轮才定位）

### 她听（STT 语音输入，stt.py + whisper_stt.py）

```
你的声音 ──麦克风(16000Hz采样)──→ 本地 faster-whisper 识别（GPU，0元/月）
   ──→ 本地没就绪 → 降级火山识别 ──→ 文字 ──→ 进聊天流
```

### 通话模式（call_mode.py + vad.py + aec.py）——像打电话

```
麦克风常开 → 音量阈值VAD（你开口了）→ 持续0.3秒才算真开口（防咳嗽误触发）
→ 你停1.2秒=说完了 → 一次性识别 → 文字进聊天流（能打断她！）
└─ 她说话时：暂停监听（半双工）+ 回声消除（AEC：拿"她刚播的内容"抵消回声）
   ——不然她自己的声音会被当成你在说话（鬼打墙）
```

**三种说话方式对比**：

| 方式 | 怎么用 | 适合 |
|---|---|---|
| 打字 | 终端直接打字 | 安静环境 |
| 按键说话 | 终端输"说"或网页点🎤 | 说完自动停 |
| 通话模式 | 输"通话开"或网页点📞 | 像打电话一样自由聊 |

### 唱歌（sing.py）

往 `data/songs/` 放 mp3 → 她说"我要唱《XXX》给你听～"（先报歌名，**等播完才开唱**——不会歌名和歌互相顶掉）→ 播放整首歌。主循环同步阻塞（真人唱歌时不接话，自然）。

## 八、她怎么"看见"你——网页形象

**打开方式**：双击项目根的 **「打开小李网页.bat」**（自动起本地服务器 + 打开浏览器）。⚠️ 不要直接双击 `web/XiaoLi.html`（file:// 方式禁止 Live2D 加载）。

```
通道1 face_state.js（data/）  ← 每2秒刷新：心情/好感/说的话/表情
通道2 WebBridge（chat.py里的HTTP小服务器，127.0.0.1:8800）
        ← 网页按钮请求它：🎤录音 / 🔊开关 / 💬开关 / 📌记住 / 📞通话 / 📷传照片 / ❤️她的心
```

网页上的形象有两层：
1. **CSS 脸**（纯代码画的表情，12种心情都有专属表情）——永远可用（兜底）
2. **Live2D 小人**（Shizuku）——**全本地**（断网也能看），会呼吸会眨眼；**微表情终局**：开心/生气/吃醋/难过都是按官方格式自己写的表情文件（angry 皱眉瞪眼/jealous 斜眼/sad 委屈/开心系眯眼），**嘴型跟着语音逐句动**（静音时闭嘴——之前"静音段嘴张着"的 bug 根治）

**网页还能干什么**（不只是看脸）：
- 底部气泡面板：最近对话，刷新不丢
- 💬 直接打字聊天（XSS 转义，安全）
- 📷 传照片 → 她看一眼回你（照片会存成高重要度记忆："他给我看过一张照片，是……"）
- ❤️ "她的心"面板：当前心情/好感/怨气 + 最近心情变迁史（5 秒自动刷新）
- 📌 记住这句：高重要度记忆

**为什么安全**：网页桥只监听你自己的电脑（127.0.0.1），不开外网；有鉴权 token；路径穿越防了、XSS 转义做了（都是真 HTTP 实测验证过的，不是纸面安全）。

## 十二、遇到问题怎么办（排查手册）

| 症状 | 原因 | 解法 |
|---|---|---|
| 窗口一闪就关 | Python 没装/没进 PATH | 重装 Python，勾选"Add to PATH" |
| 她说的话没声音 | 1.没输"语音开" 2.没运行 `--voice` 3.声卡问题 | 先看终端有没有"🔊 语音已开启"；再跑 scripts/mic_check.py 查声卡 |
| 我说话她听不到 | 麦克风权限/设备不对 | 跑 scripts/mic_check.py 看哪个设备能采声 |
| 网页打开没反应 | 聊天程序没跑 | 先跑 start.bat，再开网页 |
| 网页有表情没声音 | 网页和终端是两个东西 | 声音在终端那边，网页只负责脸和按钮 |
| 提示 API 报错 | 密钥问题/欠费/网络 | 跑 scripts/setup_keys.py 重新存密钥；检查账户余额 |
| 提醒到点没响 | 程序在运行吗？ | 提醒只在程序运行时触发（她睡着你得叫她）；关程序期间到点的会开机留话 |
| 她说的话重复/重叠 | 播放器并发 | 重启程序；还不行看 design-log M.5 节（历史大坑） |
| 传照片没反应 | 上传格式问题 | 网页传照片用裸字节（不要用表单）；魔数校验（jpg/png/gif/webp 头字节）不匹配会拒 |
| 网页"连不上" | 鉴权 token 过期 | 聊天程序启动时会写新 token（启动后刷新网页即可） |
| 想清空她的记忆 | 删 data/ 里的文件 | 备份后删，她会"失忆"重来（注意 facts.json 里的生日也没了） |
| 终端打印乱码 | 用了 emoji 打印 | 终端是 GBK 编码，打印用 [OK]/[!!] 标记，别用 emoji（start.bat 已开 utf-8） |

## 十三、维护注意事项（重要！）

1. **⚠️ 密钥保密**：API Key 存在 **Windows 凭据管理器**（scripts/setup_keys.py 设置），不写进代码文件。别截图发人、别传 GitHub。泄露=别人能用你的钱
2. **别删 data/**：她记得的一切都在这里，删了等于失忆。**改数据前先备份**（scripts/backup.py）
3. **路径统一走 paths.py**：以后挪文件位置，只改 `xiaoli/paths.py`，别在代码里写死路径
4. **改动后必跑测试**：451 项测试是安全网——跑完变红说明改坏了
5. **模块引用格式**：包内互相引用用 `from xiaoli import xxx`——**包内裸 `import xxx` 会静默失败**（语义记忆假成功就是这么来的，真实踩坑！）
6. **启动方式**：`python -m xiaoli.chat --voice`（在项目根目录）——注意是 `-m xiaoli.chat` 不是直接跑文件
7. **语音播放库**：别换回 mci/pygame——sounddevice 是踩了四轮坑换来的（design-log M.5）
8. **她的所有机制都有设计依据**：想删/改机制前，先读 design-log 对应节——很多"看起来多余的逻辑"是实测踩坑得来的
9. **显存（8G 上限）**：whisper(≈2G) + 声音克隆(≈4.9G) + 语义向量(小) 共存没问题；再上大模型会 OOM——先跑 scripts/check_vram.py 看余量
10. **测试污染真实数据**：别用测试消息直接打真实接口（会进她的对话流）——用无害 payload，测完清理

## 十四、术语表（人话版）

### 编程基础

| 术语 | 人话解释 |
|---|---|
| **代码/程序** | 给电脑看的"菜谱"：一行行指令，电脑照着做 |
| **文件 (.py)** | Python 代码文件（Python 是一种编程语言，中文名叫蟒蛇🐍） |
| **模块** | 一个 .py 文件就是一个模块：一个"零件" |
| **包 (package)** | 一个文件夹装一堆相关模块，比如 `xiaoli/` 包 |
| **函数** | 一段有名字的指令块：`def 名字():` 定义，`名字()` 调用。像"菜谱里的一步" |
| **变量** | 起名字的盒子：`age = 18` 就是"把18放进叫age的盒子" |
| **列表/数组** | 一串东西：`["奶茶","鸡排"]` |
| **字典** | 带标签的盒子：`{"名字":"小李","年龄":18}`——用标签找东西 |
| **JSON** | 数据存放格式（字典的样子）：人和程序都能读的"表格文本" |
| **循环** | 重复做某事：`while True:` 就是"永远重复"（她的心跳） |
| **线程** | 同时干几件事：一个线程打字回复你，另一个线程放声音 |
| **注释** | `#` 开头的文字，给人类看的，电脑跳过不执行 |
| **import** | "拿零件"：`import 声音` = 把声音零件的说明书拿过来用 |
| **错误/报错 (Traceback)** | 程序说"出事了"并告诉你哪里出事——**读最后一行**，别怕 |
| **测试** | 自动体检：跑一堆检查，全绿=健康 |
| **端到端 (E2E)** | 全链路实测：从"你说话"到"她回应"全程走一遍 |
| **Mock（打桩）** | 测试时不真联网，用假数据代替（不花钱、不依赖网络） |
| **假成功** | 表面上看功能正常，实际一直在用备用方案（本项目抓到过 2 次：bge 空目录、裸导入）——**检测方法：直接调生产函数看返回值** |

### 项目里的"她的零件"

| 术语 | 人话解释 |
|---|---|
| **人设/提示词 (Prompt)** | 写给 AI 看的"角色扮演剧本"（persona.py） |
| **工作台 (Workbench)** | 每次发给 AI 的全部内容打包（context.py build_workbench） |
| **摘要 (Summary)** | 把一大段聊天浓缩成几句话，防止记忆太多装不下 |
| **召回 (Recall)** | 从记忆里找相关的东西拿出来用 |
| **半衰期** | 记忆淡忘的速度：过1个半衰期记得程度减半 |
| **重要度 (Importance)** | 记忆的"重要程度"打分 1~10 |
| **好感度 (Affection)** | 她喜欢你的程度 0~100 |
| **状态机** | 程序控制"现在是什么状态"并规定怎么变（heart.py） |
| **转移约束** | 心情变化必须合理过渡的规则 |
| **程序判定轮** | 这轮她"吃醋/被哄好"是程序判的，AI 不许抢着报心情 |
| **Scheduler** | 她的"闹钟总管"：每秒检查有没有到点的提醒/主动时机 |
| **节奏窗口** | 一天里她会主动找你的时段（早安/午休/晚安） |
| **夜间静默** | 22点到8点她"假装睡了"不主动（提醒除外） |
| **主动配额** | 每天主动说话的次数限制（2次，克制才像真人） |
| **keep_talking** | 她说完后"还想不想继续说"的开关（真人会追话） |
| **continuation** | 主话之后的补充句（真人生气会连珠炮） |
| **打断机制** | 你插话→她立刻闭嘴听你（_interrupted） |
| **半双工** | 通话模式：同一时间只一方说话（她说话时她自己的"耳朵"关着） |
| **回声消除 (AEC)** | 她说话的声音被麦克风捡到→用"她刚播的内容"抵消（防鬼打墙） |
| **睡前回想 (sleep-time)** | 每晚 23 点后把当天对话整理成记忆（学自 Letta 论文） |
| **两阶段提交** | 先算完所有结果（不写状态），全部成功才写入——失败不破坏任何东西 |
| **流式朗读** | 边合成边播，不等整段完成（第一声 0.3 秒） |
| **降级链** | 首选方案挂了自动用备用方案（克隆→火山→edge） |
| **拟声 (sfx)** | 清嗓/叹气/轻笑等小声音（用她自己的声音合成） |

### AI/语音领域

| 术语 | 人话解释 |
|---|---|
| **LLM/大模型** | 超级聪明的 AI 大脑（本项目用 DeepSeek） |
| **API** | 程序之间打招呼的"公用电话"：你的程序打电话给 DeepSeek 说"帮我生成一句话" |
| **API Key** | 打电话的"账号密码"，按用量计费 → **保密！** |
| **JSON 模式** | 要求 AI 的输出严格按固定格式（方便程序解析） |
| **max_tokens** | 一次回答最多生成的字数上限（设太小会"话没说完就被掐断"） |
| **TTS** | 文字→声音（本项目优先用本地克隆音色） |
| **声音克隆** | 拿一段参考音频学会这个音色（Qwen3-TTS） |
| **STT/ASR** | 声音→文字（本项目优先用本地 faster-whisper） |
| **embedding/向量** | 把文字变成一串数字，意思相近的数字相近（embed.py） |
| **余弦相似度** | 两组向量的"像不像"评分：1=完全像，0=不像 |
| **VAD** | 声音检测：判断"有没有人说话"（通话模式用音量阈值实现，零依赖） |
| **WebSocket** | 长连接电话：一次接通长期通话（火山识别用） |
| **HTTP 服务器** | 网页和程序之间的邮局（WebBridge，127.0.0.1:8800） |
| **端口** | 邮局的一个窗口号码（8800） |
| **前端** | 用户看到的部分（网页 web/XiaoLi.html） |
| **后端** | 用户看不到的处理部分（xiaoli/ 代码） |
| **鉴权 token** | 网页桥的"口令"：对不上就不让进门（防陌生人乱用） |
| **魔数校验** | 检查文件开头几个字节是不是图片格式（防上传假文件） |
| **XSS** | 恶意代码混进网页——本项目所有渲染都做了转义防护 |
| **ONNX** | 模型的一种格式，轻量、本机就能跑（embed.py 用） |
| **GPU 显存 (VRAM)** | 显卡的"工作台内存"：本地模型都要占（8G 是天花板） |
