# 小李 2.0 · 大版本方案（从"打补丁"到"一次架构级升级"）

> 日期：2026-08-21
> 依据：4 组并行研究 × 25 篇论文 × 3 个开源项目实际代码（AIRI/SillyTavern/Open-LLM-VTuber）+ 现状盘点
> 研究详情：产品组 `version2-products.md`｜学术组 `version2-academic.md`｜代码组 `version2-code.md`｜技术组 `version2-tech.md`
> 原始材料：`docs/research/sources/`（companion-v2/ 8 份、papers-v2/ 25 篇 PDF、code-v2/ 71 个源码文件，全部体积校验通过）

## 0. 四组研究的共同信号（先说方向，再列方案）

把四组研究叠在一起看，出现三条交叉验证的主线：

1. **记忆是"像真人"的最大杠杆**——四组里有三组的第一名都是记忆（学术：三信号召回+反思提纯；代码：半衰期曲线+增量摘要；产品：夜间固化+主动挂钩记忆）。"她记得"比"她说得好"更让人有被在乎的感觉。
2. **人味 = 克制 + 不完美**——学术（Skantze：未完句"但是…"绝不接话）、代码（AIRI 防弱模型镜像："太完美的结构是 AI 味"）、产品（防 AI 味黑名单）在三个方向上得出同一结论：真人会说不完整的话、会用"嗯…"、不会每条消息都标准回应。
3. **她需要"睡前消化"机制**——Generative Agents 的反思提纯、MATE 的睡眠巩固、Drift 论文的一致性检查器，都是"每天结束时把当天的事消化成性格的一部分"。小李现在是"醒了才想"，真人感版本应该是"睡一觉后长了一点点"。

## 1. 现状痛点（为什么要升级，不升级就是补丁）

| # | 痛点 | 现在 | 后果 |
|---|---|---|---|
| 1 | 记忆检索弱 | bigram 关键词打分，≥3 分才召回 | 换种说法就"想不起来" |
| 2 | 遗忘一刀切 | 7 天统一 -1 | 重要的事和闲事一起忘 |
| 3 | 记忆与情绪脱节 | facts 里没有"当时什么心情" | 翻旧账只是复述，不会"想起时又委屈一下" |
| 4 | 摘要扁平 | 满 20 轮把最老 10 轮压成 3-8 句 | 三天前聊的细节全没（"昨天说的那个"说不出来） |
| 5 | 人格无契约 | 只有 system prompt 防御 | 论文实证大模型 8 轮就开始人设漂移，没人纠偏 |
| 6 | 声音无情绪 | 一个音色一个语速 | 生气和撒娇听起来一样 |
| 7 | 哄没章法 | 关键词触发 + LLM 临场发挥 | 可能跳过共情直接给建议（情感支持大忌） |
| 8 | 主动没理由 | 判断式主动（到点问 LLM 说不说） | 主动多是寒暄，不会"因为有话想说"才开口 |
| 9 | 全程一个脑子 | 全用 flash | 关键时刻（生气/纪念日）不会换更强模型 |
| 10 | 人味无法度量 | 只测机制对不对 | "像不像小李"没有裁判，改坏了也不知道 |

## 2. 方案总览

**P0 = 核心升级（一周）** ｜ **P1 = 体验增强（再一周）** ｜ **P2 = 可选扩展（想清楚再上）**

### P0 · 记忆引擎（她真的"记得"）

| 编号 | 机制 | 学自 | 一句话 |
|---|---|---|---|
| M1 | 三信号加权召回 | 学术·Generative Agents | 重要度×新近度×相关度归一化加权排序，替换"bigram≥3 按重要度排" |
| M2 | 半衰期连续遗忘 | 代码·AIRI | 每次查询按"相关度×exp(-小时/半衰期)"现算分，忘记是渐进的；召回一次回一次血，替代 7 天一刀切 |
| M3 | 增量链式摘要 | 代码·SillyTavern | 旧摘要当 base 让 LLM 扩展，只喂"上次摘要之后"的新消息——升级 context.py，**全方案成本最低收益最高** |
| M4 | 反思提纯 | 学术·Generative Agents | 每晚 LLM 把当天对话提成 1~3 条"结论型"事实（"他加班多，我晚上该多心疼他"）存高重要度——记忆长成性格 |
| M5 | 躯体标记 | 学术·MATE | 每条事实带"记下时的情绪"字段（valence），召回时提示"想起的感受"；高情绪事实衰减更慢（3 天起步） |
| M6 | 每日一句话摘要 | 学术·MemoryBank | 每天睡前压成一句"今天聊了什么"，翻旧账/出门跟进直接引用（"昨天你说的那个…"） |

### P0 · 人格一致性（100 轮后她还是小李）

| 编号 | 机制 | 学自 | 一句话 |
|---|---|---|---|
| C1 | 一致性检查器 | 学术·Drift 论文 | 每晚 LLM 把当天她说的话和 persona 比对，发现矛盾（人设"最爱柠檬茶"却说"讨厌柠檬"）就记一条"纠偏事实"塞回下轮 |
| C2 | 人设锚定压缩 | 学术·CharacterGPT/Drift | 摘要压缩指令加"人设要点必须在摘要里保持"，逐块锚定 |

### P0 · 情绪表现（她会"演"得更真实）

| 编号 | 机制 | 学自 | 一句话 |
|---|---|---|---|
| E1 | 独立情绪分类器 | 代码·SillyTavern | 每轮结束后一次**极短** LLM 调用（只输出一个词），判情绪标签驱动说话量/停顿——比程序规则细、比内嵌标签稳 |
| E2 | ESConv 三阶段哄 | 学术·ESConv | 她低落时注入阶段标签：探索（先问怎么了）→ 共情（复述+肯定）→ 行动（逗她/建议）——跳过共情直接给建议是情感支持大忌 |
| E3 | 情绪转移约束表 | 学术·PELD | 情绪转移白名单（吃醋→生气允许；开心→生气禁止；生气→开心必须经过哄），钳制 LLM 自报比"钳幅度"更精细 |
| E4 | 情绪化 TTS | 产品/技术组 | 火山指令式情绪（`<整体情绪：生气>`）——生气语速快音调高、撒娇软糯，不换音色零成本（免费额度内） |

### P1 · 主动与节奏（她说话有理由）

| 编号 | 机制 | 学自 | 一句话 |
|---|---|---|---|
| P1 | 主动挂钩记忆 | 产品组 | 主动开口前先召回"最近关于他的事"，有值得说的才开口；没话说就安静陪着（已有一半：判断式主动） |
| P2 | 话题规划+转移检测 | 学术·主动综述 | 主动走"最近话题链"（出门跟进已是范本）；连续 2-3 句短回复判定话题耗尽 → 她主动换题 |
| P3 | 主动事件独立小调用 | 代码·AIRI spark | 事件走**单独** LLM 调用（"可不说话"+只输出一句话），不污染主对话流、不占主回复队列、主动说的话不落日记 |
| P4 | 语境化等待 | 学术·When can I Speak | keep_talking 等待按输入类型调整：大段分享→短等；低落→长等；刚吵完→最长的耐心 |

### P1 · 工程底座（架构级）

| 编号 | 机制 | 学自 | 一句话 |
|---|---|---|---|
| T1 | 长上下文放宽 | 技术组 | 128K 原生，工作台放宽到 60 轮 + 三层摘要（滚动/每日/全局） |
| T2 | 多模型路由 | 技术组 | heart 情绪信号路由：日常 flash（1.5 元/百万）→ 生气/纪念日/表白等关键时刻换 pro（4.5 元） |
| T3 | 防镜像打磨 | 代码·AIRI | 时间戳只加 user 侧不加 assistant 侧；记忆/状态用扁平 bullet 附在最后一条 user 消息尾部（弱模型把显眼结构当数据镜像回回复——和小李"LLM 模仿 []"教训同源） |
| T4 | 人味裁判 | 学术·MT-Bench/CharacterEval | 固定 20 场景×4 维（一致性/甜度/接得住/真人感）LLM 裁判月度打分 + 记忆抽查（1h/1d/7d 三窗口）——"变好"第一次可度量 |

### P2 · 可选扩展（想清楚再上，不影响主线）

| 编号 | 机制 | 学自 | 成本 |
|---|---|---|---|
| O1 | Live2D 形象 | 技术组 | 1-2 天（pixi-live2d-display + Shizuku 免费模型）——她会动、有表情 |
| O2 | 通话模式 | 技术组 | 一期半双工约 1 秒响应（silero-vad 常开监听） |
| O3 | 向量记忆 | 技术组 | bge-small-zh-v1.5 24M 本地 CPU 5.8ms/条，语义检索替换 bigram（M1 接口不变，以后想上直接换） |
| O4 | 网页"记住这句"按钮 | 产品组 | 小半天 |
| O5 | 里程碑/纪念日预告链 | 产品组 | 14/7/1 天预告 |
| O6 | 本轮"工作记忆"待办 | 学术·A-Mem | 他说"待会给你看照片"→ 下轮带出（"照片呢～"） |
| O7 | 打断后记得没说完 | 现状痛点 | 打断时存半句话，下轮带出 |

## 3. 成本与路线

### 路线 A：只做 P0（约 1 周）——推荐起步
记忆引擎（M1-M6）+ 一致性（C1-C2）+ 情绪表现（E1-E4）。
用户能直接感觉到：她记得更清楚、忘得更自然、哄得更像样、生气时声音真的不一样、100 轮后还是那个人。
**成本**：零新增外部依赖（情绪 TTS 在火山免费额度内），全本地逻辑升级。前 3 项（M1/M2/M3）只改两个文件（memory.py 打分函数 + context.py 摘要）。

### 路线 B：P0 + P1（约 2 周）
加上主动升级和工程底座。她开始"因为有事才说话"，关键时刻换更聪明的脑子，人味有裁判。

### 路线 C：全上（约 3 周，含 P2 可选里挑几项）
想清楚 Live2D / 通话模式 / 向量记忆要不要再走这条。

## 4. 决策点（等你拍板）

| # | 决策 | 选项 | 影响 |
|---|---|---|---|
| 1 | **范围** | A（P0 一周）/ B（P0+P1 两周）/ C（全上） | 决定本轮工作量 |
| 2 | **多模型路由 T2** | 要 / 不要 | 成本 +30~60%（只在关键时刻用 pro）；不要就继续全程 flash |
| 3 | **情绪化 TTS E4** | 要 / 不要 | 免费额度内；要的话我先做"生气/撒娇两种情绪实测试听"给你 A/B |
| 4 | **Live2D O1** | 要 / 不要 / 以后再说 | 1-2 天工作量，她会动有表情；不要就保持纯 CSS |
