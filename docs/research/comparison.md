# 小李 vs 市面上高 star 的 AI 伴侣项目（对比，2026-08-20）

> 对比对象均为**实际下载读过代码/规范**的项目（证据在 sources/）。star 数为印象中的数量级，
> 当前网络无法直连 GitHub 验证，只保证方向正确。商业产品（Replika/CAI/星野）无代码可读，基于公开报道与逆向分析。

## 一、对比对象一句话

| 项目 | 是什么 | 代码量级 | 大众认可度 |
|---|---|---|---|
| **SillyTavern** | 角色扮演聊天前端（接各家 AI API），角色卡生态标准制定者 | 大型 JS 项目 | 高 star，开源 RP 圈事实标准 |
| **Open-LLM-VTuber** | 会动的 VTuber 女友：本地大模型+Live2D+语音 | 中型 TS 项目 | 高 star，VTuber 伴侣标杆 |
| **UTSUWA** | 3D 实时伴侣：完整情绪状态机+关系系统+语音 | 中型 TS/Svelte 项目 | 高 star，开源伴侣状态机设计最佳 |
| **Replika / Character.AI / 星野** | 商业 AI 伴侣（闭源，无代码可读） | — | 大众产品，付费可用 |
| **小李** | 台湾甜妹伴侣：双轨对话+情绪+记忆+主动+语音+形象 | 小型纯 Python 项目 | 你自己从零攒的 |

## 二、逐维度对比

| 维度 | SillyTavern | Open-LLM-VTuber | UTSUWA | 小李 |
|---|---|---|---|---|
| 人格塑造 | 角色卡：**示例对话为主**（官方卡 personality 字段是空的，"演给你看"） | 静态 persona 文本（纯 prompt） | 人设+状态注入 | 人设+示例对话+状态注入（ST 和 UTSUWA 的都用上了） |
| 情绪状态机 | 无（全靠模型临场发挥） | 无（只提取情绪驱动表情） | **完整**：情绪+强度0-100+原因causes+消退+钳制 | **完整**：同上 + 小脾气闭环（触发→升级→哄→和好）+ 气不过夜 |
| 关系系统 | 无 | 无 | 五维关系值（好感/信任/亲密/舒适/尊重）+ 衰减 | 好感 + 48h 衰减 + 72h 忧郁 + 吵架记忆（REPAIR） |
| 主动互动 | 世界书/作者注（按条件注入） | 无 | 事件表驱动（时间/关系/冷落时长条件） | 判断式主动（LLM 决定说不说）+ 每日配额 + 夜间静默 + 提醒 + 出门跟进 + 吃醋触发 |

| 自动化测试 | 无 | 无 | 少量 | **115 项单元 + 17 项端到端**（每次改动全链路验证） |

## 三、结论：小李学到了什么、还差什么

### 学到的（已落地，实测有效）
1. **状态机路线**（UTSUWA）：情绪+强度+causes 注入，LLM 自报被程序钳制——"App 是游戏主持人"
2. **示例对话塑造人格**（SillyTavern 官方卡）：吃醋/真生气/心软三段"演给你看"
3. **哄→和好闭环**（哄哄模拟器+ZifaMem REPAIR）：哄的效果程序定，和好记一笔记忆
4. **粗话稀缺使用**（PTT 实测）："靠北喔"只在生气峰值一次
5. **主动要克制**（Replika 教训）：每日配额 2 次 + 夜间静默 + 提醒豁免

### 还差的（大项目有、我们没有，按性价比排）
| 差距 | 大项目怎么做 | 值不值得学 | 说明 |
|---|---|---|---|
| 动态形象 | Live2D/3D 实时渲染 | 想做 | CSS 脸已能用；Live2D 是大工程，列为后续候选 |
| 向量检索记忆 | 全量历史语义检索 | 可选 | 我们有档案+召回，够用；语义检索是锦上添花 |
| 本地模型 | 完全离线 | 可选 | 云端 DeepSeek 便宜够用，离线是隐私换体验 |
| 插件/生态 | 社区贡献 | 不需要 | 单项目反而清爽，无依赖风险 |
| 多角色/群聊 | 多卡切换 | 不需要 | 小李就一个，专一更好 |

### 小李的独特优势（大项目没有的）
1. **完整闭环可验证**：情绪、记忆、主动、提醒、小脾气全部有自动化测试——SillyTavern/Open-LLM-VTuber/UTSUWA 都没有这个
2. **小而全**：一个 Python 项目里跑通"对话+情绪+记忆+主动+语音+形象"全链路，UTSUWA 最接近但代码量是几十倍
3. **中文台湾人设**：繁体+台语口语+PTT 语感研究，大项目默认英文
4. **程序兜底不赌模型自觉**：提醒标签重试、触发检测、钳制——大项目全靠模型临场发挥

> 一句话：**大项目赢在形象和技术规模，小李赢在机制闭环和可验证**——她学的是大项目设计里最值钱的部分（状态机、示例对话、克制），而不是它们的工程规模。
