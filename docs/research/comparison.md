## 三、结论：小李学到了什么、还差什么

### 已从新项目吸收（2026-08-23 落地）
1. **Letta sleep-time compute**（arXiv:2504.13171）→ **睡前回想**：每晚 23 点后整合当天对话成记忆（两阶段提交，失败明天再试）——夜间静默窗口从"假装睡了"升级为"睡了也在成长"
2. **Mem0 ADD-only** → 验证小李 `merge_fact` 只加不覆盖已达标（同内容只更新重要度，不覆盖原文）
3. **Open-LLM-VTuber skip_history** → 验证小李 keep_talking 走主动链路不伪装用户消息已达标
4. **Open-LLM-VTuber display/TTS 分离** → 验证小李 inner_thought/spoken 双轨天然实现已达标（内心话不念出来）
5. **CleanS2S 拉黑模式** → 验证小李"一整天不理她"小脾气闭环已是同类实现
6. **Open-LLM-VTuber 逐句情绪** → **自研升级版落地**：OLV 让 LLM 内联 `[joy]` 逐句提取（flash 会漏标），小李改为**程序注入**——连珠炮结构是程序钉死的（翻旧账→控诉→委屈收尾），程序按序号+文本特征给每句标情绪（收尾"呜…"→sad、其余→angry），语音语气+网页表情逐句变，零 LLM 纪律风险

### 学到的（已落地，实测有效）——早期
1. **状态机路线**（UTSUWA）：情绪+强度+causes 注入，LLM 自报被程序钳制——"App 是游戏主持人"
2. **示例对话塑造人格**（SillyTavern 官方卡）：吃醋/真生气/心软三段"演给你看"
3. **哄→和好闭环**（哄哄模拟器+ZifaMem REPAIR）：哄的效果程序定，和好记一笔记忆
4. **粗话稀缺使用**（PTT 实测）："靠北喔"只在生气峰值一次
5. **主动要克制**（Replika 教训）：每日配额 2 次 + 夜间静默 + 提醒豁免

### 还差的（大项目有、我们没有，按性价比排）

|---|---|---|---|

### 小李的独特优势（大项目没有的）
1. **完整闭环可验证**：情绪、记忆、主动、提醒、小脾气全部有自动化测试（451 项）——SillyTavern/OLV/UTSUWA/Mem0 都没有这个量级的伴侣级验证
2. **小而全**：一个 Python 项目里跑通"对话+情绪+记忆+主动+语音+形象+世界认知+唱歌"全链路
3. **中文台湾人设**：繁体+台语口语+PTT 语感研究，大项目默认英文
4. **程序兜底不赌模型自觉**：提醒四层保险（SILENT/重试/留话/让位）、情绪程序判定、结构钉死——大项目全靠模型临场发挥
5. **0 元语音**：声音克隆 + 本地 whisper 全离线，大项目要么付费要么用默认音

> 一句话：**大项目赢在形象、规模和生态，小李赢在机制闭环、可验证、人设细节和成本**——她学的都是大项目设计里最值钱的部分（状态机、记忆范式、克制），而不是它们的工程规模。
