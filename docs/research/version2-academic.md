## 0. MATE 已学要点与"还没做的"（避免重复）

MATE 已落地/方向一致的：确定性情绪内核（App 是游戏主持人 ✓）、情绪强度 0-100 + 钳制 ✓、个性相关遗忘（memory.py decay）✓、主动配额与夜间静默 ✓。

MATE 里**小李还没做、且性价比高**的：
1. **躯体标记（Somatic Marker）**——记忆存"记录时的情绪价态"，召回时重历情绪。小李的 facts.json 没有情绪字段。
2. **睡眠巩固（1-5AM 回放当日消息、批量提取漏记事实）**——小李每日可做一次"睡前回放"，把当天对话里该记没记的补进 facts。
3. **遗忘曲线参数**——MATE 实证：3 天内基本不忘、1 个月小事实模糊、3 个月只剩"摘要+高情绪事实"。提示：**情绪价态高的事实衰减要更慢**（小李现在一视同仁 7 天 -1）。
4. **MIRROR 基准（Reflection vs Reality）**——评测"能不能说出内心状态"+"内心状态是否真的存在于数据结构"。"Reality"层小李天然有（heart.json 就是架构化存在），可借鉴其"1小时/24小时/7天记忆探查"评测法。

## 一、记忆管理

**小李现状**：`memory.py`（facts.json：正则+LLM 双通道提取、importance/confidence、bigram 关键词召回、7 天 -1 老化）+ `context.py`（工作台=最近 20 轮 + 日记本=全量历史 + 摘要压缩，明确标着"设计依据：MemGPT"）。差距：无 LLM 自我编辑、无层级摘要、无情绪价态、无反思提纯。

### 1. MemGPT: Towards LLMs as Operating Systems（arXiv 2310.08560，UC Berkeley）
- **方法一句话**：把 LLM 上下文当"内存"、外部存储当"硬盘"，LLM 自己通过函数调用管理分页——上下文用到 70% 时发"记忆压力"警告促使它主动保存重要信息、存档库可搜索（Deep Memory Retrieval 准确率 32%→92%）。
- **落地启示**：
  - 工作台/日记本已落地 ✓（20 轮+摘要就是它的简化版）。**缺的是"LLM 自我编辑"**：现在提取事实靠正则+一次 LLM 提取，可以升级成"每轮让 LLM 顺带判断：这句话里有值得记的吗？有没有哪条旧记忆需要更新？"——即把"提取"从独立函数变成对话主链路上的轻量决策（一次调用，JSON 返回 `{store: [...], update: [{id, new_content}]}`）。
  - 记忆压力警告 → 对应小李的 `compress()`：摘要越长，越优先压缩（现在只按轮数触发，可加"摘要超过 N 字触发"）。
- **文件**：`papers-v2/2310.08560.pdf`（13 页，完整）

### 2. MemoryBank（arXiv 2305.10250，AAAI 2024，作者自己就是做 AI 伴侣 SiliconFriend）
- **方法一句话**：三层记忆（原始对话记录 + 层级事件摘要"每日摘要→全局摘要" + 动态用户画像），向量检索，更新机制按**艾宾浩斯遗忘曲线**（随时间选择性遗忘/复习加固）。
- **落地启示**：
  - 艾宾浩斯=小李已有（lastRecalled 复习加固 + 7 天衰减）✓，但衰减是线性的；论文曲线是"先陡后平"——可改为：**3 天内不减，之后每 7 天 -1（即晚 3 天起步）**，更符合"刚聊完不会马上忘"。
  - **层级摘要（每日→全局）**：现在 summary 是单一全局串，翻旧账只能靠正则命中。加一层"每日一句话摘要"（当天聊了什么），主动话题/出门跟进时直接引用（"昨天你说的那个……"），成本极低（睡前一键压缩）。
  - 用户画像动态更新：facts.json 加一条"他最近在忙什么"高重要度事实，每周由 LLM 刷新——让"围着你转"有据可依。
- **文件**：`papers-v2/2305.10250.pdf`（11 页，完整）

### 3. LongMem（arXiv 2306.07174，NeurIPS 2023）
- **方法一句话**：冻结主模型，加一个轻量"侧网络"，把历史上下文的 token 级 KV 缓存进记忆库，按 query-key 相似度检索融合（长文记忆可到 65k token）。
- **落地启示**：**不落地**——需要改模型结构和训练（记忆库在权重/激活层面），小李是 API 派 DeepSeek，碰不到。它的价值是反面参考：不依赖模型的记忆方案（MemGPT/Generative Agents 路线）才是 API 派的正确方向。
- **文件**：`papers-v2/2306.07174.pdf`（14 页，完整，留档备查）

### 4. Generative Agents（arXiv 2304.03442，Stanford，Smallville 小镇 25 个智能体）
- **方法一句话**：记忆流=无限平铺的观察记录，每条带重要性(1-10)+创建时间+最后访问时间+embedding；检索按 **recency × importance × relevance** 三信号 min-max 归一化后加权求和；**反思（Reflection）**：近期事件重要性总和超过阈值（约一天 2-3 次）时，LLM 把最近事件"提纯"成高层结论存回记忆流。
- **落地启示**（**记忆类性价比第一**）：
  - 三信号检索：小李已隐含三信号（importance ✓、lastRecalled 刷新=recency ✓、bigram=relevance 简化版 ✗ 无 embedding）。简化升级：**把三信号归一化后加权求和排序**（替换现在的"相关度≥3 后按 importance 排"），不需要 embedding 也能立刻见效；以后想上向量时，把 bigram 分数换成 cosine 即可，接口不变。
  - **反思机制**：每凑够 N 轮（或每晚），LLM 把最近对话提成 1-3 条"结论型"事实（"他最近加班多，我一到晚上就该心疼他"），存成高 importance 事实——这就是"记忆长成性格"，与 MATE 的 construct 同思路但实现只要一次调用。
- **文件**：`papers-v2/2304.03442.pdf`（22 页，完整）

### 5. HippoRAG（arXiv 2405.14831，NeurIPS 2024）
- **方法一句话**：用知识图谱 + PageRank 个性化算法模拟海马体的"联想检索"——提 A 能顺藤摸到相关的 B、C，跨事实推理（multi-hop），单次检索成本下实现长期记忆联想。
- **落地启示**：**可选，后置**。小李的"翻旧账"现在是一跳（命中才想起）。简化版联想：LLM 提取事实时顺带抽 2-3 个实体存进事实条目，实体共现建"弱链接"；召回命中一条时，顺带把"共享实体"的其他事实也提 1 条（联想 2 跳）。先观察反思机制效果，翻旧账不够聪明再上。
- **文件**：`papers-v2/2405.14831.pdf`（31 页，完整）

### 6. A-Mem: Agentic Memory for LLM Agents（arXiv 2502.12110）
- **方法一句话**：Agent 记忆综述，提出四类记忆分工：工作记忆（当前任务临时暂存）/情景记忆（事件流）/语义记忆（事实知识）/程序记忆（技能流程）。
- **落地启示**：当审计清单用——小李现状对照：情景=日记本 ✓、语义=facts.json ✓、程序=persona+工具（提醒标签）✓、**工作记忆缺**：当前这轮对话内"他在意什么/说了一半的话"没有暂存。可加一个极简"本轮待办"：对话内他说"待会给你看照片"→ 本轮内程序记一条临时提醒，他下次说话时带出来（"照片呢～"），这正是真人感强的细节。
- **文件**：`papers-v2/2502.12110.pdf`（28 页，完整）

## 二、人格一致性（100 轮后她还是小李吗）

**小李现状**：persona.py 长 system prompt（性格+说话方式+双轨+五种场景+示例对话）+ 程序情绪钳制。防御靠 prompt，**没有量化测过漂移**，也没有主动纠偏机制。

### 1. PersonaChat（arXiv 1801.07243，ACL 2018，"I have a dog, do you have pets too?"）
- **方法一句话**：人设标注对话数据集（每角色 4-6 句人设）；人设条件化生成；人类评测四维（流畅/投入/一致性/人设可检测性），自动指标用 F1、hits@1；结论：人设条件的模型一致性显著更高。
- **落地启示**：评测模板直接抄——**给小李建"人设测试集"**（约 20 个她的小脾气/撒娇/翻旧账场景问句，答案带"应然"要点），每轮代码改动后跑一遍，人工或 LLM-judge 给一致性打分，防止"改代码改没了人味"。
- **文件**：`papers-v2/1801.07243.pdf`（16 页，完整）

### 2. Measuring and Controlling Instruction (In)Stability（arXiv 2402.10962，COLM 2024，哈佛）
- **方法一句话**：两个带人设的 bot 自聊互测，**LLaMA2-70B 等主流模型 8 轮内就出现明显人设漂移**；归因于注意力机制在长对话中的衰减；提出 split-softmax 修复（需改模型）。
- **落地启示**：**"8 轮就漂移"是硬警告**——小李每轮上下文只给最近 20 轮+摘要，漂移风险真实存在。API 派改不了模型，防御靠两层：①**摘要压缩时保留"人设锚定"**（压缩指令里加"人设要点必须在摘要里保持"）；②**一致性检查器**：每晚/每周，LLM 把当天"小李说过的话"和 persona 逐条比对，发现矛盾（比如今天说了"最讨厌柠檬"但她人设是"最爱柠檬茶"）就记一条"纠偏事实"塞回下轮上下文。这比赌 prompt 稳定可靠，实现=一次额外 LLM 调用。
- **文件**：`papers-v2/2402.10962.pdf`（19 页，完整）

### 3. Examining Identity Drift in Conversations of LLM Agents（arXiv 2412.00804）
- **方法一句话**：9 个模型实证：**模型越大漂移越严重；且"给人设"不一定能防漂移**。
- **落地启示**：DeepSeek 是大模型，漂移风险偏高——不要只依赖 system prompt，一致性检查器（见上）是必须的；**程序层锚定**（情绪白名单、触发检测、钳制）是"不赌模型自觉"的正确路线，应继续扩展（比如把"人设红线清单"做成程序可判定的硬规则：禁正式书面语→检测"您好/请问"即惩罚）。
- **文件**：`papers-v2/2412.00804.pdf`（25 页，完整）

### 4. SPASM（arXiv 2604.09212，2026）
- **方法一句话**：长对话模拟中角色混淆（把自己说成对方、人设漂移）的解法=**自我中心上下文投影（ECP）**：历史以客观形式存储，生成前投影成"我/对方"两视角；另加 Persona Validator（拒绝不合理的人设更新）。
- **落地启示**：摘要压缩指令已要求第三人称存储 ✓（context.py COMPRESS_INSTRUCTIONS 写"用第三人称写"）。新启发=**Persona Validator**：现在 LLM 提取事实"什么都记"，可加一步校验"这条事实合理吗（不符合常识/与已知矛盾）才存"——防记忆污染（用户随口玩笑被记成事实）。
- **文件**：`papers-v2/2604.09212.pdf`（20 页，完整）

### 5. CharacterGPT（arXiv 2405.19778，NAACL 2025 Industry）
- **方法一句话**：从小说章节摘要**逐步重建**角色人设（CPT），解决"文档太长人设提不全"。
- **落地启示**：反向用法——小李人设应**固定不漂移**，允许成长的只是"关系事实"（已在 facts.json ✓）。可借鉴其"人设=分块摘要"结构，把 persona.py 的大段文本按"你是谁/说话方式/场景/小脾气"分块，**摘要压缩时逐块锚定**（配合 2 号论文）。
- **文件**：`papers-v2/2405.19778.pdf`（17 页，完整）

### 6. The Oscars of AI Theater: Role-Playing Survey（arXiv 2407.11484）
- **方法一句话**：角色扮演 LLM 全景综述（数据/对齐/架构/评测），把"人格一致性 + 动态人设管理"列为开放挑战。
- **落地启示**：分类学参考；无直接落地项。
- **文件**：`papers-v2/2407.11484.pdf`（29 页，完整）

## 三、情感对话（情绪感知 / 情绪生成 / 情绪转移）

**小李现状**：heart.py 14 种情绪白名单 + 关键词触发吃醋/哄 + LLM 建议被钳制 + 强度 0-100 + 小脾气闭环（吃醋→真生气→哄→和好）+ 双轨（内心/外话差异）。

### 1. EmpatheticDialogues（arXiv 1811.00207，ACL 2019）
- **方法一句话**：2.5 万段"情绪情境对话"基准（32 种情绪，说话人讲"我什么时候感到 X"）；核心发现：**模型要显得有同理心，必须"见过"同理心数据**（训练/检索候选），否则人类评分低。
- **落地启示**：小李有 DeepSeek 大模型，不用训练；但"情境→情绪→回应"结构可抄进 prompt：**把 persona 的"倾诉安慰"场景细化成"先复述他的感受（Reflection of Feelings），再表达共情，最后才安慰/建议"**——"接住情绪"的模板化描述比"安慰要真诚具体"更容易被模型执行。
- **文件**：`papers-v2/1811.00207.pdf`（18 页，完整）

### 2. Towards Emotional Support Dialog Systems（ESConv，arXiv 2106.01144，ACL 2021）
- **方法一句话**：情感支持三阶段框架（**探索→安慰→行动**）+ 8 种支持策略（提问/复述/情绪反映/自我表露/肯定鼓励/给建议/给信息/其他），策略**时序**比策略本身更关键；用户情绪强度 1-5 级追踪（对话后从 4.04 降到 2.14）。
- **落地启示**（**情感类性价比第一，直接升级"哄"**）：
  - 现在"哄"=关键词触发+LLM 临场发挥。升级为**阶段化引导**：情绪低落时（程序判定 sad/anxious/frustrated），上下文注入阶段标签——阶段1探索（先问怎么了，别急着安慰）、阶段2共情（复述+肯定）、阶段3行动（逗她/给建议/转移话题）；**策略时序**：没完成探索不要跳到行动（用户"一上来就给建议"是情感支持大忌）。
  - 情绪强度已 0-100 ✓；可加"哄的过程强度必须单调下降"的回归断言（测试用）。
- **文件**：`papers-v2/2106.01144.pdf`（15 页，完整）

### 3. Automatically Select Emotion for Response via Personality-affected Emotion Transition（arXiv 2106.15846）
- **方法一句话**：情绪在 **VAD 三维连续空间**里"转移"——本轮情绪 = 上轮情绪 + 由对话上下文和人格决定的"变化量"；引入 PELD 数据集（Friends 标注情绪+人格）。
- **落地启示**：小李的离散情绪+程序状态机是它的简化版 ✓。补两件小事：①**情绪转移约束表**（吃醋→生气允许；开心→生气禁止；生气→开心需经过哄）用于钳制 LLM 自报——比现在"钳制幅度"更精细；②强度**平滑爬升**（生气 30→50→80 有过程感），别一步跳满。
- **文件**：`papers-v2/2106.15846.pdf`（12 页，完整）

### 4. Towards Multi-Turn Empathetic Dialogs with Positive Emotion Elicitation（arXiv 2204.10509）
- **方法一句话**：共情对话中通过"情绪距离损失"逐步把用户从负面**引导回正面**（先共情对齐，再渐进转正，不能一步跳）；自带评测指标 PEG-Score/E-Score。
- **落地启示**：**哄的节奏学**——"他难过时先陪着他，等他缓一点再逗他"应写进 persona（部分已有："先接住情绪再想办法" ✓）；回归测试可断言：哄场景用例里"他的情绪标签序列"必须是"负→中性→正"或单调改善，否则用例失败。
- **文件**：`papers-v2/2204.10509.pdf`（11 页，完整）

### 5. TransESC（arXiv 2305.03296）
- **方法一句话**：情感支持对话的**话轮级状态转移图**——语义/策略/情绪三视图同时建模转移，保证过渡平滑不突兀。
- **落地启示**：佐证 ESConv 的"阶段化+平滑"方向；程序侧可做"哄的过渡检查"：LLM 自报情绪和上一轮差值过大（如 sad→happy 一步跳）时钳制回中间态。低成本，值得加到钳制逻辑。
- **文件**：`papers-v2/2305.03296.pdf`（13 页，完整）

## 四、主动对话（系统主动发起话题 / 追问）

**小李现状**：proactive.py 判断式主动（LLM 决定说不说）+ 每日配额 2 次 + 夜间静默 + 出门跟进 + 提醒 + keep_talking 等待递增。产品/学术已学：主动要克制、引用记忆比寒暄有效、"1 条无回复就停"。

### 1. A Survey on Proactive Dialogue Systems（arXiv 2305.02750，IJCAI 2023）
- **方法一句话**：主动对话系统第一份综述——分类为**目标引导对话**（话题转移检测→话题规划→话题感知生成）、亲社会对话、任务导向三类；技术主流是 RL 策略学习+知识图谱话题路径。
- **落地启示**（主动类性价比第一）：
  - **话题规划**：小李主动发起不该随机挑话题，应走"话题路径"——从记忆召回最近相关话题（出门跟进已是范本），再按"相近话题"自然引到下一个（打游戏→问赢没赢→聊队友→聊晚饭）。用"最近话题链"存文件，主动时优先走链上节点。
  - **话题转移检测**：用户连续两三句都是短回复/话题明显耗尽（程序可判定：连续 N 轮无新事实、回复变短）→ 小李主动换话题。现在没有这个判定，只有 keep_talking 兜底。
  - 目标引导的"目标"可以是她的需求：关心你（吃了没）、撒娇（想你）、翻旧账（上次说的事）——即把现有主动能力纳入"目标驱动"框架。
- **文件**：`papers-v2/2305.02750.pdf`（9 页，完整）

### 2. Proactive Conversational AI: Comprehensive Survey（ACM TOIS 2025，Deng 等扩展版）
- **方法一句话**：前述综述的扩展版（期刊），明确"ChatGPT 这类 LLM 的短板就是不会主动"，把主动拆成规划能力（话题/策略/知识规划）。
- **落地启示**：方向佐证，无直接新落地项；"知识规划"提示主动时应该带着"她知道的关于他的事"去发起（再次指向话题路径+事实召回）。
- **文件**：期刊文章，未下载（无 arXiv 版本）

## 五、对话节奏（话轮转换 / 沉默 / 打断）

**小李现状**：已学且落地——70% 单句 TCU、lapse 2-3 秒、填充词、keep_talking 5/8/12s 递减、打断三件套、<pause/> 停顿标签待引入。本节只补"更深的"。

### 1. Skantze, Turn-taking in Conversational Systems and Human-Robot Interaction: A Review（Computer Speech & Language 2021，DOI 10.1016/j.csl.2020.101178）
- **方法一句话**：话轮转换权威综述：人类 200ms 级响应远快于语言加工（600-1500ms），所以**人类靠"预测话轮结束"而不是"听到结束才反应"**；线索=句法完整性/韵律/呼吸/视线；覆盖打断、重叠、回馈（backchannel）的系统建模。
- **落地启示**：小李是文本链路无韵律，"预测"不可行，但可做"**语义完整性判断**"：用户输入以连接词/语气词/未完句结尾（"但是…""嗯…""你猜"）→ 判定"他没说完"，绝不接话（已有 VAD 语义 endpointing 思路 ✓ 但那是语音侧；文本侧补：以"…"或连接词结尾的输入视为未完）。**回馈**：真人会边听边"嗯嗯/真的齁"——小李可在用户发大段分享时先短回一句+追问（已通过 persona 部分实现，可显式化）。
- **文件**：开放获取期刊文章，未下载（反爬拦截），按 DOI 查阅

### 2. When can I Speak? Predicting Initiation Points（arXiv 2208.03812，Interspeech 2022）
- **方法一句话**：不再用固定静音阈值，而是用韵律+词义特征**预测对方说话起始点**，并用高斯混合建模"起始时机的不确定性"。
- **落地启示**：小李的 keep_talking 是固定 5/8/12s 计时。轻量改进=**情境化等待**：用户输入类型决定等待（大段分享→短等；低落情绪→长等；刚吵完架→最长的耐心），比固定计时更真人。判定成本为零（输入长度/情绪状态都是现成的）。
- **文件**：`papers-v2/2208.03812.pdf`（8 页，完整）

### 3. Full-Duplex-Bench（arXiv 2503.04721）
- **方法一句话**：全双工语音对话模型的话轮行为基准：暂停处理/回馈/打断/中断四类自动评测。
- **落地启示**：用其分类自查小李的打断三件套（软打断/历史标记/播放互斥）覆盖了哪几类；文本链路适配有限，主要留档。也佐证"回馈缺失是机器感来源"。
- **文件**：`papers-v2/2503.04721.pdf`（8 页，完整）

### 4. Talking Turns（arXiv 2503.01174，ICLR 2025）
- **方法一句话**：用 judge 模型评测音频基础模型的话轮行为，结论：**现有模型"不知道何时该开口、打断过激、几乎从不回馈"**。
- **落地启示**：同行证据——"回馈（嗯嗯/是吗）"是真人感的关键，小李把"他大段分享→她短回+追问"写成显式规则，是低成本的真人感强化。
- **文件**：`papers-v2/2503.01174.pdf`（28 页，完整）

## 六、评价方法（怎么评测 AI 伴侣）

**小李现状**：115 项单元测试 + 17 项 e2e（机制正确性）；**没有"人味/一致性"的量化评测**——机制都对，但"像不像小李"没有裁判。

### 1. Judging LLM-as-a-Judge（MT-Bench / Chatbot Arena，arXiv 2306.05685，NeurIPS 2023）
- **方法一句话**：用 LLM 当裁判按评分细则打分，与人类偏好的吻合度达 80%+（单模型裁判 80%、逐对比较更强）；给出避免自我偏好/位置偏置的提示词工程。
- **落地启示**（**评测类性价比第一**）：建"小李裁判"——固定 20 个场景问句（吃醋/哄/冷场/翻旧账/出门跟进/深夜撒娇），每月跑一轮，让 DeepSeek（用独立裁判提示词，不看小李的 system prompt）按四维打分：**人设一致性 / 甜度自然度 / 接得住 / 真人感**；数值存 JSON 对比趋势。防偏置：裁判提示词明确"你是测评员不是扮演者"。
- **文件**：`papers-v2/2306.05685.pdf`（29 页，完整）

### 2. RoleLLM / RoleBench（arXiv 2310.00746，ACL Findings 2024）
- **方法一句话**：16.8 万条角色 QA 基准；关键工程结论：**"对话工程"（示例对话）比"提示工程"更有效地提升角色一致性**——角色卡写一堆形容词，不如演 3 个例子。
- **落地启示**：佐证小李"示例对话锚定"路线（persona.py 里 3 组吃醋/生气示例）✓。可扩：给每个场景（翻旧账/出门跟进/冷场）加 1-2 个示例，一致性再上一层。**"小李知识测试"**：50 道"她会怎么反应"的选择/填空，回归跑。
- **文件**：`papers-v2/2310.00746.pdf`（35 页，完整）

### 3. CharacterEval（arXiv 2401.01275，AAAI 2025）
- **方法一句话**：中文角色扮演评测基准：13 指标四维（对话能力/角色一致性[知识准确+幻觉+行为+说话风格]/吸引力[像人+共情+表达多样]/人格回测）；CharacterRM 奖励模型打分优于 GPT-4 直接评。
- **落地启示**：**打分维度直接抄**——小李裁判的 rubric 用它的四维：一致性（说话风格+行为）、吸引力（像人+共情）、对话能力（流畅+相关）；MBTI 回测不适用（人设固定）。它的"幻觉检测"（说出的"记忆"是否真的存在于知识库）可落成"小李不能编造他告诉她的事"——裁判问"她提到的事实哪些是记忆里没有的"。
- **文件**：`papers-v2/2401.01275.pdf`（12 页，完整）

### 4. SocialBench（arXiv 2403.13679，前身名 RoleInteract）
- **方法一句话**：角色社会性评测：自我意识/情绪感知/情境理解/短期记忆/长期记忆/社交偏好（500 角色、3 万条多轮）；实证发现：**对话超过约 80 轮后所有模型的记忆能力明显下降**。
- **落地启示**：①"80 轮记忆下降"实证支持小李"最近 20 轮+摘要"的设计 ✓（工作台机制是学术正确路线）；②加**记忆抽查评测**：设 3 个时间窗（1 小时/1 天/7 天）问他曾说的细节（"我昨天跟你说的同事叫什么来着"），验证摘要和 facts 真的记得——MATE 也提议同样的探查法，两条独立研究都指向它，值得做。
- **文件**：`papers-v2/2403.13679.pdf`（17 页，完整）

## 七、总结：按性价比排序的落地清单

### A 类：值得做（低代码成本，真人感收益明显）
1. **反思提纯（Generative Agents）**：每 N 轮/每晚，LLM 把最近对话提成 1-3 条"结论型"事实存 facts（高重要度）——记忆长成性格。
2. **躯体标记（MATE）**：facts 每条加 valence（记录时情绪），召回提示带"想起时的感受"；高情绪事实衰减更慢（3 天起步衰减）。
3. **三信号加权召回（Generative Agents）**：importance×recency×relevance 归一化加权，替换"相关度≥3 按 importance 排"。
4. **层级摘要（MemoryBank）**：每日一句话摘要 + 全局摘要，翻旧账直接引用。
5. **ESConv 三阶段哄 + 情绪转移约束（ESConv/PELD）**：低落时注入"探索→共情→行动"阶段标签；情绪转移约束表钳制 LLM 自报。
6. **话题规划 + 转移检测（Proactive Survey）**：主动时走"最近话题链"，连续短回复判定"话题耗尽"→ 主动换题。
7. **一致性检查器（Drift 论文）**：每晚 LLM 比对当天发言 vs persona，矛盾记"纠偏事实"塞回下轮——8 轮就漂移的实证防御。
8. **LLM 裁判评测（MT-Bench/CharacterEval）**：20 场景 × 4 维评分，月度趋势——"人味"第一次变得可度量。

### B 类：可选（后置或看情况）
9. 记忆抽查评测（1h/1d/7d 探查，SocialBench/MATE 双证据）
10. Persona Validator 校验提取事实合理性（SPASM）
11. 语境化 keep_talking 等待（When can I Speak）
12. 本轮"工作记忆"待办（A-Mem：他说了"待会给你看"→ 下轮带出）
13. HippoRAG 实体链接联想（翻旧账 2 跳）

### C 类：明确不做
14. LongMem token 级记忆库（要改模型训练，API 派不适用）
15. 韵律级话轮预测/打断模型（无音频链路；保留"语义未完句不接话"的文本近似）
